# Hand WiLoR

API gratis para [Hand Landmark Studio](https://pablopoletti.github.io/hand-landmark-studio/).

Recibe una foto y devuelve los 21 landmarks (2D normalizados + 3D MANO) con [WiLoR-mini](https://github.com/warmshao/WiLoR-mini).

Hardware recomendado en Hugging Face: **CPU basic** (gratis, más lento) o **ZeroGPU** si tu cuenta lo permite.
